# AI Infrastructure Failure Analysis

## Objective

Automatically analyze Terraform deployment failures.

## Features

- Detects Terraform failure
- Captures error log
- Sends prompt to OpenAI
- Generates Root Cause
- Suggests Fixes
- Provides Verification Commands

## Example

Terraform Apply

↓

Failure Detected

↓

terraform_error.log

↓

OpenAI API

↓

AI Failure Analysis

↓

GitHub Job Summary
